This is a basic 3D Game that consists of 3 platforming challenges.
To make it the best for both experienced players and casual players I have included many ways to go about the challenges, 
whether that's a shorter and harder route or a more streamlined easier route.

I have changed the player character's stats in order to accommodate this change perfectly (or as close as one can be anyway).
Jump Height: 1.5 (allows for the rock climbing challenge to be more bearable)
Walk Speed: 4 (just right for casual players and helps in the rock climbing section)
Run Speed: 10 (for experienced players, as well as for the last challenge to be possible, I like to feel a sense of freedom which this speed gives.)

I only used Terrain Assets for the second challenge, which can be found here: https://assetstore.unity.com/packages/3d/environments/landscapes/terrain-asset-pack-terrain-sample-145808
The rest of the textures are basic materials with changed color and a custom texture I made in Paint for the shift hint in the 3rd Challenge.

This hint is to let all players know that whether or not they have been using shift to sprint, they must do so for the final challenge.
It serves to ramp up the difficulty from beginning to end to feel like there's a sense of progression and game knowledge.
